Section 3 • Architecture

Core Features Grid

Parallel Multi-Ecosystem Scanning

Queries 5 package registries concurrently via Tokio async runtime with connection pooling and non-blocking I/O.

RuntimeTokio Async I/O

SemVer Risk Classification

Intelligently classifies version jumps into ● Safe, ● At-Risk, and ● Breaking while filtering unstable pre-releases.

RulesStrict SemVer 2.0

Standalone Interactive HTML

Self-contained ~55KB offline HTML report with zero external CDN dependencies, auto-opens in default browser.

Footprint54 KB Standalone

Section 4 • Quickstart

Get Started in 3 Steps

No runtime baggage or external language interpreters required.

Step 1: Clone & Install
$cargo install --path .
Step 2: Scan Repository
$rustydeps scan .
Step 3: Auto-Open Report
Opens self-contained interactive rustydeps-report.html directly in your default browser.

Tip: RustyDeps returns exit code 1 on breaking changes for CI/CD pipeline gating.
