# Opencode Prompt — Issue #21: UI Font Scaling & Branding (Favicon + Logo)

> **Goal:** Fix small font sizes across the HTML report, add an inline SVG logo next to the title, and set an embedded SVG favicon.
> **Target File:** `templates/report.html`
> **Branch:** `feat/ui-branding-fonts` from `development`
> **Issue:** Closes #21

---

## 1. Context & Objective

The current HTML report (`templates/report.html`) uses `text-xs` (12px) in many table cells, badges, and drawers, making text hard to read on high-resolution screens. Additionally, the report lacks a favicon and branding icon next to the "RustyDeps" header.

Opencode can apply these changes directly to `templates/report.html` without external layout tools.

---

## 2. Implementation Steps

### A. Font Size Adjustments in `templates/report.html`
Update Tailwind typography classes:
- **Table Data & Headers:** Change `text-xs` (12px) to `text-sm` (14px, `leading-relaxed`).
- **Cards & KPI Subtitles:** Change `text-xs` to `text-sm`, and `text-sm` to `text-base` (16px).
- **Drawer Detail Logs & Monospace Code:** Change `text-[11px]` / `text-xs` to `text-sm` (14px) for better code readability.
- **Header Title:** Keep `text-xl` or `text-2xl` bold.

### B. Favicon (Embedded Data URI)
Add the following line inside the `<head>` section of `templates/report.html`:
```html
<link rel="icon" type="image/svg+xml" href="data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24' fill='none' stroke='%2338bdf8' stroke-width='2' stroke-linecap='round' stroke-linejoin='round'%3E%3Cpath d='M12 2v4M12 18v4M4.93 4.93l2.83 2.83M16.24 16.24l2.83 2.83M2 12h4M18 12h4M4.93 19.07l2.83-2.83M16.24 7.76l2.83-2.83'/%3E%3Ccircle cx='12' cy='12' r='4'/%3E%3C/svg%3E">
```

### C. Header Brand Logo
In the `<header>` section, place this inline SVG right before `<h1>RustyDeps</h1>`:
```html
<div class="flex items-center gap-3">
  <svg class="w-7 h-7 text-sky-400" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <path d="M12 2v4M12 18v4M4.93 4.93l2.83 2.83M16.24 16.24l2.83 2.83M2 12h4M18 12h4M4.93 19.07l2.83-2.83M16.24 7.76l2.83-2.83"/>
    <circle cx="12" cy="12" r="4"/>
  </svg>
  <h1 class="text-xl font-bold tracking-tight text-slate-100">RustyDeps</h1>
</div>
```
