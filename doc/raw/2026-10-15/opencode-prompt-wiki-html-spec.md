# TASK: Update LLM-Wiki with HTML Report UI Specification & Stitch Iteration Findings

## Context
Through an iterative UI design process using Google Stitch, we have defined and finalized the UX/UI architecture for the interactive HTML report generated by RustyDeps. 

We need to update the project LLM-Wiki in `doc/wiki/` to document this final HTML report design specification, architectural decisions, component hierarchy, and risk visualization standards.

---

## Instructions

### Step 1 — Create/Update HTML Report Spec Page (`doc/wiki/html-report-spec.md`)
Create a new wiki page `doc/wiki/html-report-spec.md` with OKF-compliant YAML frontmatter (`title`, `type`, `description`, `status`, `version`, `license`, `created`, `updated`, `tags`):

Document the following finalized design & architectural choices:

1. **Design Philosophy (Industrial Dark Mode / Developer-First):**
   - Dark theme palette based on Zinc (`#09090b` background, `#18181b` card surfaces, `#27272a` 1px borders).
   - Strict prohibition of glossy gradients, glassmorphism, or translucent "AI" badges.
   - Monospace typography (`JetBrains Mono` / `SF Mono`) for crate names, SemVer numbers, and terminal commands; geometric sans-serif (`Geist Sans` / `Inter`) for UI elements.

2. **Project-Centric Component Hierarchy:**
   - Instead of a flat list/table of dependencies, items are grouped by **Project/Repository** (e.g., `backend-api`, `web-dashboard`, `ml-worker`).
   - Each project header displays its ecosystem badge (`CARGO`, `NPM`, `PYPI`, `GO`), manifest file path, summary risk breakdown, and a project-level `Update All` action popover/command.

3. **Minimalist Risk Indicators:**
   - Solid 6px dot indicators with sRGB contrast compliance:
     - `● major` (Breaking changes / red)
     - `● minor` (At-risk / amber-yellow)
     - `● patch` (Safe updates / green)
   - Zero saturated background pills behind risk tags.

4. **Discrete AI Changelog Summaries:**
   - Removal of prominent purple "AI Insight" banners.
   - Replaced by a subtle `AI` tag in neutral grey (`zinc-400`) alongside concise 1-line release summaries.

5. **Interactive Component Specifications:**
   - **Inline Dependency Drawer:** Clicking a package row expands an in-line drawer containing the full AI changelog and a terminal snippet with a one-click copy button for CLI update commands (e.g. `cargo update -p tokio --precise 2.0.0`).
   - **Filter & Search Bar:** Global filter pills (`All`, `● Breaking`, `● At-Risk`, `● Safe`) and search input (`/` or `⌘K`).
   - **Empty State Component:** Minimalist fallback display when search or filters match 0 dependencies.
