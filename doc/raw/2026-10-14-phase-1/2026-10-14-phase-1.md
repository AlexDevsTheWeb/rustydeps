### Step 3: Implement File System Scanner (`src/scanner.rs`)
1. **Supported Manifest Enum:**
   Create an enum `ManifestType` supporting:
   - `CargoToml` (`Cargo.toml`)
   - `PackageJson` (`package.json`)
   - `GoMod` (`go.mod`)
   - `RequirementsTxt` (`requirements.txt`)
   - `PyprojectToml` (`pyproject.toml`)
   - `ComposerJson` (`composer.json`)

2. **Discovered Project Struct:**
   ```rust
   pub struct DiscoveredManifest {
       pub path: std::path::PathBuf,
       pub manifest_type: ManifestType,
   }
   ```

3. **Scanner Function:**
   Implement `pub fn scan_directory<P: AsRef<std::path::Path>>(root: P) -> anyhow::Result<Vec<DiscoveredManifest>>`:
   - Use `ignore::WalkBuilder` to walk the directory tree while automatically ignoring files matching `.gitignore`, `.ignore`, and hidden directories (e.g. `.git`, `node_modules`, `target`).
   - Identify supported manifest files and return a list of `DiscoveredManifest`.

4. **Unit Tests:**
   Include unit tests in `src/scanner.rs` using a temporary directory (e.g., `tempfile`) to verify that `.gitignore` rules are respected and manifests are correctly detected.
